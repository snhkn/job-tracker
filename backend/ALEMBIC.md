# Alembic – Database Migration Guide

Alembic manages database schema changes.

## When I change a SQLAlchemy model

1. Make the change in `app/models.py`.
2. Generate a migration:

   ```bash
   alembic revision --autogenerate -m "describe the change"
   ```

3. Open the generated file in `alembic/versions/`.
4. Review the `upgrade()` and `downgrade()` functions.
5. Apply the migration:

   ```bash
   alembic upgrade head
   ```

## Useful commands

| Command | Purpose |
|---|---|
| `alembic current` | Show current database revision |
| `alembic history` | Show migration history |
| `alembic upgrade head` | Apply all pending migrations |
| `alembic downgrade -1` | Revert one migration |
| `alembic heads` | Show migration heads |

## Important reminders

- Run commands from the `backend` directory.
- Never blindly trust autogenerated migrations.
- Commit migration files to Git.
- Do not commit local `.db` files.
- Do not delete the database to apply schema changes.
- Back up important data before risky migrations.
